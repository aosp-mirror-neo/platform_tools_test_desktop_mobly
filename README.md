# Desktop Mobly tests and test libraries

## tests/
Mobly tests go here. The tests are organized by project/team. Further organization under project/team is up to the OWNERS of that folder.
## lib/
Code that is not tests goes here. Organized by the functionality it provides, and intended to be used by mobly/tests code.
## tools/
Scripts or other types of tools that are not used by the tests directly. Organized by the functionality they provide.
